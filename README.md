# 🎯 Do it! Backend API

### 📌 프로젝트 소개

**Do it! Backend API**는 **할 일 관리 웹 애플리케이션(**[Do it](https://todo-list-delta-nine.vercel.app/)**)** 백엔드 서버입니다.
할 일의 생성, 조회, 수정, 삭제(CRUD) 기능과 이미지 업로드 기능을 제공하는 RESTful API를 구현합니다.

### ✨ 주요 기능
#### 할 일 관리 (Todo Items)
- **할 일 목록 조회**: 전체 할 일 목록을 페이지네이션과 함께 조회
- **할 일 생성**: 새로운 할 일 항목 생성
- **할 일 상세 조회**: 특정 할 일의 상세 정보 조회
- **할 일 수정**: 할 일의 제목, 완료 상태, 메모, 이미지 URL 수정
- **할 일 삭제**: 할 일 항목 삭제

#### 이미지 관리
- **이미지 업로드**: 할 일에 첨부할 이미지 파일 업로드 (최대 5MB)
- **이미지 URL 반환**: 업로드된 이미지의 접근 가능한 URL 제공

### 🛠️ 기술 스택
- **NestJS**: 11.x
- **TypeScript**: 5.x
- **Prisma**: 7.x
- **PostgreSQL**: (pg 8.x)
